----------------
Installation
----------------

::

   pip install "git+https://github.ic.ac.uk/aeronautics/invenio-ldapclient.git"


For development::

  git clone https://github.ic.ac.uk/aeronautics/invenio-ldapclient.git
  cd invenio-ldapclient
  pip install -e '.[dev]'
